## Exact commands

```bash
# Full package
./run_all.sh --workers 8

# Software-only smoke validation
./run_all.sh --smoke --workers 1 --skip-tex

# Compile final TikZ after the paper run
for source in plotting/tikz/*.tex; do
  latexmk -pdf -interaction=nonstopmode -halt-on-error -cd "$source"
done
```

Every plotted numerical curve can be regenerated from CSV without rerunning a simulation. The plotting scripts never import the experiment scripts.
